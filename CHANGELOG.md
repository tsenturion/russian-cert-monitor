# Изменения

## 0.9.0

- Добавление и импорт в чёрный список используют постоянный запрет компьютера. При подтверждённом запрете Windows прежняя пользовательская запись переносится в общий режим.
- Разблокировка снимает прямой запрет компьютера и текущей учётной записи. Приложение показывает результат цепочки после снятия.
- Монитор обнаруживает исчезновение записи запрета компьютера и для сертификатов других стран.

## 0.8.0

- Добавлена локальная проверка цепочки Windows отдельно для пользователя и компьютера.
- После изменения Disallowed приложение проверяет фактический запрет, показывает результат обеих областей и сохраняет его в истории.
- Добавлены фильтры, сведения о доверии в отчётах и предупреждение о снятии запрета или восстановлении доверия.

## 0.7.0

- Подготовлен публичный репозиторий: сборка Windows в GitHub Actions, архив дистрибутива и инструкции разработки.
- Публичный справочник удостоверяющих центров отделён от локальной истории удаления сертификатов.
- В репозиторий не включаются настройки, журналы, отчёты, экспортированные сертификаты и приватные ключи.
- Недоступный диагностический журнал больше не прерывает запуск; после восстановления доступа запись возобновляется.

## 0.6.0

- Обнаружение российских сертификатов во всех доступных логических хранилищах CurrentUser и LocalMachine.
- Мониторинг в трее, сохранение состояния и уведомления без повторов неизменных совпадений.
- Свойства и публичный экспорт CER, ручное добавление и удаление Disallowed с подтверждением и UAC.
- Настройки, пользовательские правила, история событий и отчёты JSON/TXT.
- Целевые интеграционные проверки, упаковка и установка в автозагрузку Windows.
