# Разработка

Требуются Windows 10/11 x64 и .NET SDK из `global.json`. Все пользовательские сообщения, комментарии и документация проекта пишутся по-русски.

```powershell
dotnet restore .\tests\RussianCertMonitor.Tests\RussianCertMonitor.Tests.csproj
dotnet build .\tests\RussianCertMonitor.Tests\RussianCertMonitor.Tests.csproj -c Release --no-restore
```

Запускайте только проверки изменённых компонентов. Маршруты `--catalog`, `--stage2`, `--stage3`, `--stage4`, `--stage5` описаны в README. Они не изменяют настоящие хранилища сертификатов.

`verify_release.ps1` выполняет интеграции с изолированным тестовым сертификатом в CurrentUser Disallowed и удаляет его в `finally`. Административные проверки запускаются отдельно; Root и CA не изменяются. Не используйте настоящие рабочие сертификаты как тестовые данные.

Новые изменения существенной логики должны сохранять диагностику между запусками с ограничением хранения 30 дней. Не добавляйте сетевые запросы в обычный цикл сканирования и не считывайте приватные ключи.

Не включайте в коммиты локальные журналы, настройки, дампы хранилищ, экспортированные сертификаты и данные конкретного компьютера. Публичный справочник содержит сведения об удостоверяющих центрах; персональная история хранится только локально.

Лицензия для проекта пока не выбрана.
