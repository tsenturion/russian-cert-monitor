# RussianCertMonitor для Windows x64

Приложение обнаруживает российские сертификаты в логических хранилищах текущего пользователя и компьютера. Управление Disallowed выполняется вручную. Настройки, история и отчёты доступны через окно и меню трея.

## Установка

Требуются Windows 10/11 x64 и установленный .NET Windows Desktop Runtime 10 x64. В этом архиве обычная сборка с одним EXE; runtime в архив не включён.

Распакуйте архив в отдельную папку. Откройте PowerShell в этой папке и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_startup.ps1
```

Скрипт копирует EXE в автозагрузку текущего пользователя и запускает его. Окно открывается двойным щелчком по значку в трее или повторным запуском установленного EXE. Закрытие окна возвращает приложение в трей; выход доступен в меню значка.

Пользовательские данные хранятся отдельно в `%LOCALAPPDATA%\RussianCertMonitor` и переживают обновление EXE. Для изменений LocalMachine приложение запрашивает права администратора через UAC. Отмена подтверждения не меняет хранилище.

## Обновление и удаление

Для обновления распакуйте новый архив и повторите установку. Будет остановлен только экземпляр из точного пути автозагрузки.

Для удаления выберите «Выход» в меню трея и удалите `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\RussianCertMonitor.exe`. Настройки и историю можно сохранить либо удалить отдельно по своему решению. Удаление приложения само по себе не меняет записи Disallowed.

## Границы проверки

Признаки российской принадлежности не доказывают вредоносность. CurrentUser может наследовать записи LocalMachine. Приложение не проверяет отдельные хранилища Firefox, Java и других пользователей. Опрос по умолчанию выполняется каждые 10 секунд; краткое появление между проверками может остаться незамеченным.

Ошибки доступа отображаются явно. История и диагностические журналы сохраняются не более 30 дней. Приватные ключи не экспортируются; работа приложения не требует сетевых запросов или КриптоПро.
